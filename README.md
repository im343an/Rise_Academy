# Rise Academy Management System

A Laravel-based web application developed for Rise Academy to manage students, classes, teachers, attendance, salaries, and academic progress.

## 🚀 Features

- Student registration and management  
- Class-wise teacher assignment  
- Weekly reports with class improvement tracking  
- Fee status and salary calculations  
- Admin dashboard with essential analytics  
- Custom marks entry and performance tracking  

## 🛠 Tech Stack

- **Backend**: Laravel 11  
- **Frontend**: Blade, Bootstrap  
- **Database**: MySQL  
- **Authentication**: Laravel default authentication system (no external packages used)
- **Other Tools**: Laravel Eloquent, Validation, Middleware

## 📂 Project Structure

Follows Laravel’s standard MVC architecture:

- `app/Models` – Eloquent models  
- `app/Http/Controllers` – Application logic  
- `resources/views` – Blade templates  
- `routes/web.php` – Web routes
